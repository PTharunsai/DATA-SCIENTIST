# DATA-SCIENTIST
# ✈️ United States Airlines Analysis – Capstone Project 2

## 📌 Project Overview
This project is part of my Data Scientist course and focuses on analyzing the **United States airline industry** using real-world datasets. The goal is to apply data science techniques to uncover insights about airline performance, customer behavior, and operational efficiency.

## 🎯 Objectives
- Collect and clean airline-related data from multiple sources.
- Perform **exploratory data analysis (EDA)** to identify trends and patterns.
- Build and evaluate **predictive models** for flight delays and cancellations.
- Create **visualizations** to communicate findings effectively.
- Provide actionable insights that can help improve airline operations and customer satisfaction.

## 🛠️ Tools & Technologies
- **Programming Languages:** Python (Pandas, NumPy, Scikit-learn), R  
- **Data Visualization:** Matplotlib, Seaborn, Power BI, Tableau  
- **Databases:** SQL for querying and organizing data  
- **Version Control:** Git & GitHub for collaboration and project tracking  

## 📊 Key Analysis Areas
- Flight delays and cancellations across major U.S. airlines  
- Seasonal and regional travel patterns  
- Customer satisfaction metrics  
- Airline market share and competition trends  
- Predictive modeling for operational efficiency  

## 🚀 Outcomes
- Cleaned and structured datasets ready for analysis.  
- Interactive dashboards and visualizations to highlight insights.  
- Predictive models that estimate the likelihood of delays.  
- Recommendations for airlines to improve service reliability.
